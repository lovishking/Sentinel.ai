# Changelog

All notable changes to the Sentinel AI project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - Initial Milestone

### Added
- Multi-agent incident investigation workflow orchestrated with LangGraph and Google Gemini.
- Real-time dark-mode operational dashboard built with Next.js App Router and TanStack Query.
- PostgreSQL storage with `pgvector` support for semantic RAG search across codebase context.
- Automated code patch synthesis and pull request generation pipeline.
- Docker Compose setup with Redis and PostgreSQL container health checks.
- Comprehensive GitHub Actions CI workflows for linting, typing, and Docker validation.
- Standardized error handling, request timing middleware, and structured logging in Express backend.
